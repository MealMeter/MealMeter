이용 안내

MealMeter는 로그인 없이, 이름을 남기지 않고 급식을 평가하는 서비스예요.

왜 평가해야 하나요?

급식에 대한 불만은 말로만 오가고 어디에도 쌓이지 않아요. 양이 부족한 건 예산으로 풀 수 있지만, 맛과 품질은 평가 데이터가 있어야 고칠 수 있어요. 여러분이 남긴 별점과 태그가 모이면 어떤 메뉴가 왜 아쉬웠는지 숫자로 보여 줄 수 있어요.

평가하는 방법

  1. 오늘의 메뉴에서 평가할 메뉴의 "평가하기" 버튼을 눌러요.
  2. 별점(1~5점)을 골라요. 별점은 꼭 골라야 등록할 수 있어요.
  3. 원하면 항목별 태그를 골라요. 같은 태그를 다시 누르면 취소돼요.
  4. 하고 싶은 말이 있으면 의견을 100자까지 써요. (선택)
  5. 평가 등록을 누르면 바로 평가 목록 맨 위에 보여요.

태그 설명

간
짜다 / 적당 / 싱겁다
양
많다 / 적당 / 적다
온도
뜨겁다 / 적당 / 차갑다
식감
무름 / 적당 / 딱딱
위생
문제 있음 / 없음 — 이물질이 나왔거나 상한 것 같을 때 골라 주세요. 다른 태그와 달리 눈에 띄게 표시돼요.

인기 순위는 어떻게 정하나요?

지금까지 쌓인 평가의 평균 별점이 높은 순서로 보여 줘요. 같은 메뉴가 다른 날 또 나오면 메뉴 이름을 기준으로 하나로 합쳐서 계산해요.

지켜 주세요

  • 메뉴에 대한 의견만 써 주세요. 특정인(조리원, 친구 등)을 향한 글은 삼가 주세요.
  • 욕설이나 비방 표현이 들어간 의견은 등록되지 않아요.
  • 로그인이 없어서 같은 사람이 여러 번 평가하는 걸 막지 못해요. 한 메뉴에 한 번만 솔직하게 평가해 주세요.
